# Geist webfonts

Unmodified variable WOFF2 files from the official [Vercel Geist repository](https://github.com/vercel/geist-font), downloaded on 2026-10-16. These files are self-hosted by `next/font/local`; loading the application does not contact a font provider.

| --- | --- | --- | --- |
| `Geist-Variable.woff2` | [Geist variable webfont](https://github.com/vercel/geist-font/blob/main/fonts/Geist/webfonts/Geist%5Bwght%5D.woff2) | 1.800 | `2ffebe993e969069a9789d15164b7715d42491b5835516c5e3b935d5f81b05f1` |
| `GeistMono-Variable.woff2` | [Geist Mono variable webfont](https://github.com/vercel/geist-font/blob/main/fonts/GeistMono/webfonts/GeistMono%5Bwght%5D.woff2) | 1.700 | `afaacc4c5fbba89d2ebf7a02dc4070208540874592a5504d57175782fe893101` |

Both contain the U+20B9 Indian rupee glyph and support the `wght` axis from 100 to 900. UI text uses weights of at least 400. Geist Sans is the primary interface family; Geist Mono is used for time labels, prices and other existing numeric details with tabular figures.
